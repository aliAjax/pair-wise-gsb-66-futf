# 铁路轨道几何缺陷整治与复测平台

基于Vue3、Vuetify、Pinia、Vue Router、Apollo Client、GraphQL、Vite和TypeScript的独立前端工程，使用Canvas绘制里程图。业务数据本地持久化。

## 功能

- 区段、里程、轨距、高低、方向和三角坑检测数据。
- Canvas里程分布、超限点定位、缺陷三角标记和缩放。
- 缺陷筛选、批量派工、工区责任和重复缺陷关联。
- 打磨、捣固、更换、垫板调整等整治记录，复测轮次与关闭校验。
- 正式限速与临时限速冲突联查，区段版本递增。
- 离线补录说明、完整审计和整治报告导出。

## 轨检车补测纠偏批次

检测数据版本、缺陷重定位和区段限速版本接入**同一纠偏批次（CorrectionBatch）**：

- 同区段同补测日期为同一导入窗口；两个窗口同时导入时，先到版本生效，后到内容完整保留为「待复核」，复核通过才生效并取代前批（前批内容保留备查），同一文件摘要拒绝重复导入。
- 批次按完整检测批次生成原子落地计划（操作键序列 + 全部对象内容）并随批次持久化；写入失败后从完整批次恢复，重试只处理未落地对象，已生效版本不重复改动（页面可注入各阶段失败演示恢复）。
- 里程变化后未关闭缺陷立即按窗口前基线重新定位、绑定新检测版本；历史复测结论标记失效并回退「待复测」重算，失效合格复测不能用于关闭。
- 已关闭缺陷保留关闭时里程与复测依据（closedBasis），按新里程生成复议项，可「维持关闭」或「重新立项」。
- 页面、里程图（批次色带/金圈采样点/琥珀失效标记/复议空心三角）、审计（批次列+批次筛选）和导出报告显示同一批次。
- 旧数据（v1 持久化）启动时自动迁移：采样点按测量时间与文件摘要回填检测版本，缺陷按发现时间窗口确认，无法确认的先「待核」，已关闭缺陷补齐当时依据。
